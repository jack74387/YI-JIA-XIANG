### 4. API 設計

#### 4.1 前台 API
- ✅ `POST /api/v1/orders` - 建立訂單
- ✅ `GET /api/v1/orders/{id}` - 查看訂單詳情
- ✅ `GET /api/v1/user/orders` - 用戶訂單列表
- ✅ `PUT /api/v1/orders/{id}/status` - 更新訂單狀態

#### 4.2 後台 API
- ✅ `GET /api/v1/admin/orders` - 後台訂單列表
- ✅ `GET /api/v1/admin/orders/{id}` - 後台訂單詳情
- ✅ `PUT /api/v1/admin/orders/{id}/status` - 後台狀態更新
- ✅ `GET /api/v1/admin/orders/export` - 匯出訂單

### 5. 權限控制

- ✅ 前台用戶只能查看自己的訂單
- ✅ 後台管理員可以查看所有訂單
