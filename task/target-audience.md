# 目標客群分析

| 客群類型           | 特徵與需求                                               | 主要使用情境                                   |
|--------------------|--------------------------------------------------------|------------------------------------------------|
| 回流客 / 在地熟客   | 信任品牌、熟悉產品、重視快速購買與到店自取             | 線上快速下單、到店自取                         |
| 辦公室團購主       | 需求量大、重視團購優惠、指定到貨日期                    | 洽談團購折扣、指定公司送達                     |
| 年輕族群           | 喜愛新奇、重視包裝與品牌故事、易受社群行銷吸引          | 社群活動導流、限量搶購、推薦商品加購           |
| 精緻送禮客         | 注重禮盒包裝、客製化需求、希望傳遞心意                  | 禮盒加值服務、代寫卡片、精美包裝               |
| 重視食安的家長     | 關心成分來源、食品履歷、健康無添加                      | 查詢食品履歷、安心選購                         |
