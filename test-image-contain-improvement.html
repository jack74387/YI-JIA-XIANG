🖼️ 推薦商品圖片完整顯示改進

改進說明

將推薦商品的圖片從 object-cover（裁切填滿）改為 object-contain（完整顯示）， 確保圖片不會被切到，用戶能看到商品的完整外觀。

object-fit 屬性比較

object-cover（改進前）

class="w-full h-48 object-cover"

特點：填滿容器，但可能裁切圖片

object-contain（改進後）

class="w-full h-48 object-contain"

特點：完整顯示圖片，不裁切

與商品頁面的一致性

商品頁面主圖樣式：
.main-img { width: 100%; height: 100%; object-fit: contain; border-radius: 8px; background: #f9f6f1; }
推薦商品圖片樣式（改進後）：
class="w-full h-48 object-contain rounded-lg bg-[#f9f6f1] border"
✅ 兩者都使用 object-contain 確保圖片完整顯示

優缺點分析

✅ object-contain 優點

  • 圖片完整顯示，不會被裁切
  • 保持原始比例
  • 用戶可以看到商品全貌
  • 與商品頁面主圖風格一致
  • 適合展示商品細節

⚠️ 需要注意的點

  • 可能在容器內留白
  • 不同比例圖片高度可能不一致
  • 需要統一的背景色（已設置 #f9f6f1）
  • 圖片尺寸差異較明顯

實際修改內容

// 修改前 class="w-full h-48 object-cover rounded-lg bg-[#f9f6f1] border" // 修改後 class="w-full h-48 object-contain rounded-lg bg-[#f9f6f1] border"

步驟 1： 訪問商品詳情頁面

觀察推薦商品的圖片顯示效果

確認圖片沒有被裁切，可以看到完整的商品外觀
步驟 4： 比較商品主圖
對比商品頁面主圖與推薦商品圖片的顯示方式
步驟 5： 測試不同比例圖片
查看不同商品圖片的顯示效果

背景色的重要性

為什麼需要 bg-[#f9f6f1]？
當使用 object-contain 時，如果圖片比例與容器不符，會在圖片周圍產生空白區域。 設置統一的背景色可以：
  • 提供視覺上的一致性
  • 避免突兀的白色空白
  • 與商品頁面主圖保持相同的背景色
  • 營造溫暖的品牌色調

適用場景

object-contain 最適合：
✅ 商品展示（需要看到完整外觀）
✅ 藝術品、食品等需要完整呈現的商品
✅ 用戶需要準確了解商品外觀的場景
✅ 與主商品圖片風格保持一致的需求
