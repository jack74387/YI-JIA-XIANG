# 註冊登入功能更新說明

## 更新內容

### 1. 後端 API 修改

#### 註冊 API (`/api/v1/auth/register`)
- **新增欄位**：
  - `phone`: 手機號碼（必填，唯一）
  - `birthday`: 出生日期（必填）
- **保留欄位**：
  - `name`: 姓名（必填）
  - `email`: 電子信箱（必填，唯一）
  - `password`: 密碼（必填，至少6位）
  - `password_confirmation`: 密碼確認（必填）

#### 登入 API (`/api/v1/auth/login`)
- **修改欄位**：
  - `login`: 登入帳號（可以是手機號碼或電子信箱）
  - `password`: 密碼

### 2. 前端介面更新

#### 註冊頁面 (`/register`)
- **新增欄位**：
  - 手機號碼輸入框（帶有格式驗證）
  - 出生日期選擇器
- **改善功能**：
  - 即時表單驗證
  - 更清晰的錯誤訊息顯示
  - 手機號碼格式驗證（09開頭，10位數字）
  - 電子信箱格式驗證
  - 密碼強度檢查

#### 登入頁面 (`/login`)
- **修改功能**：
  - 支援手機號碼或電子信箱登入
  - 改善錯誤訊息顯示
  - 更清晰的表單標籤

### 3. 錯誤訊息改善

#### 後端驗證錯誤
- 提供中文錯誤訊息
- 詳細的欄位驗證說明
- 統一的錯誤回應格式

#### 前端錯誤顯示
- 即時表單驗證
- 清晰的錯誤圖示
- 可關閉的錯誤訊息
- 分類顯示不同類型的錯誤

## 使用方式

### 註冊流程
1. 填寫姓名
2. 輸入手機號碼（將作為登入帳號）
3. 輸入電子信箱
4. 選擇出生日期
5. 設定密碼並確認
6. 提交註冊

### 登入流程
1. 輸入手機號碼或電子信箱
2. 輸入密碼
3. 點擊登入

## 技術細節

### 資料庫變更
- 手機號碼欄位已存在於 `users` 表中
- 出生日期欄位已存在於 `users` 表中
- 無需額外的資料庫遷移

### API 端點
- 註冊：`POST /api/v1/auth/register`
- 登入：`POST /api/v1/auth/login`

### 前端驗證規則
- 手機號碼：09開頭，共10位數字
- 電子信箱：標準電子信箱格式
- 密碼：至少6個字元
- 出生日期：不能是今天或未來日期
