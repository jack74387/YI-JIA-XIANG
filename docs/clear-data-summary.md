### 1. Artisan 命令
```bash

php artisan member:clear

# 強制清除（跳過確認）
php artisan member:clear --force
```

### 2. 獨立腳本
```bash
# 執行清除腳本
php clear-member-data.php
```

### 3. 快速清除
```bash
# 只清除會員帳號
php artisan tinker --execute="App\Models\User::where('is_admin', false)->delete();"
```
