## 技術實現細節

### 資料庫結構
- 使用現有的 `users` 表結構
- `phone` 和 `birthday` 欄位已存在
- 無需額外的資料庫遷移

### API 端點
- 註冊：`POST /api/v1/auth/register`
- 登入：`POST /api/v1/auth/login`

### 前端驗證
- 手機號碼：`/^09\d{8}$/` 正則表達式
- 電子信箱：標準格式驗證
- 密碼：最少6字元
- 出生日期：不能是今天或未來

### 安全性
- 密碼加密儲存
- Token 認證
- 輸入驗證和清理
- 錯誤訊息不洩露敏感資訊

## 使用流程

### 註冊流程
1. 用戶填寫姓名
2. 輸入手機號碼（將作為登入帳號）
3. 輸入電子信箱
4. 選擇出生日期
5. 設定密碼並確認
6. 提交註冊
7. 系統驗證並創建帳戶

### 登入流程
1. 用戶輸入手機號碼或電子信箱
2. 輸入密碼
3. 系統自動判斷登入方式
4. 驗證憑證並登入
