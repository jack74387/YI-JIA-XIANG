## 🧮 計算規則

### 基本規則
```
消費金額 ÷ 100 = 基本點數（取整數）
```

### 生日當月規則
```
最終點數 = 基本點數 × 2（如果為生日當月）
```

### 計算範例
| 消費金額 | 基本點數 | 生日當月 | 最終點數 |
|---------|---------|---------|---------|
| 80 元   | 0 點    | 否      | 0 點    |
| 150 元  | 1 點    | 否      | 1 點    |
| 250 元  | 2 點    | 否      | 2 點    |
| 300 元  | 3 點    | 是      | 6 點    |
| 500 元  | 5 點    | 否      | 5 點    |
| 800 元  | 8 點    | 是      | 16 點   |

## 🚀 使用方式

### 1. 自動點數累積
當用戶建立訂單時，系統會自動：
1. 計算訂單總金額
2. 根據滿百元消費累積一點的規則計算點數
3. 檢查是否為生日當月，如果是則雙倍點數
4. 將點數累積到用戶帳戶
5. 記錄點數交易歷史

### 2. 查看點數
- 會員中心顯示當前點數
- 點數頁面查看詳細歷史記錄
- API 端點查詢點數資訊

### 3. 測試功能
- 訪問 `test-points-earning.html` 進行功能測試
- 執行 `php scripts/test-points.php` 進行單元測試
