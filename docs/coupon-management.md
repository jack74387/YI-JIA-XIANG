# 優惠券管理功能說明

## 功能概述

本系統實現了完整的優惠券管理功能，包括後台管理員的優惠券 CRUD 操作和前台用戶的優惠券領取、使用功能。

## 後端實現

### 1. 資料庫結構

#### coupons 表
- `id`: 主鍵
- `name`: 優惠券名稱
- `code`: 優惠券代碼（唯一）
- `type`: 折扣類型（percent/fixed）
- `value`: 折扣值
- `min_order`: 最低訂單金額
- `expires_at`: 有效期限
- `usage_limit`: 使用次數限制
- `used_count`: 已使用次數
- `description`: 描述
- `is_active`: 是否啟用

#### user_coupons 表
- `id`: 主鍵
- `user_id`: 用戶 ID
- `coupon_id`: 優惠券 ID
- `is_used`: 是否已使用
- `used_at`: 使用時間
- `order_id`: 使用的訂單 ID

### 2. 模型功能

#### Coupon 模型
- `isValid()`: 檢查優惠券是否有效
- `canBeUsedByUser()`: 檢查用戶是否可以使用
- `calculateDiscount()`: 計算折扣金額
- `discount_text`: 取得折扣顯示文字
- `status_text`: 取得狀態文字

#### UserCoupon 模型
- 記錄用戶的優惠券領取和使用情況

### 3. API 端點

#### 前台 API
- `GET /api/v1/coupons`: 取得優惠券列表
- `POST /api/v1/coupons/redeem`: 兌換優惠券
- `POST /api/v1/coupons/validate`: 驗證優惠券（結帳時）
- `GET /api/v1/coupons/user`: 取得用戶的優惠券

#### 後台 API
- `GET /api/v1/admin/coupons`: 優惠券列表（管理員）
- `POST /api/v1/admin/coupons`: 新增優惠券
- `GET /api/v1/admin/coupons/{id}`: 優惠券詳情
- `PUT /api/v1/admin/coupons/{id}`: 更新優惠券
- `DELETE /api/v1/admin/coupons/{id}`: 刪除優惠券
- `GET /api/v1/admin/coupons/export`: 匯出優惠券資料

## 使用流程

### 管理員操作流程
1. 登入後台管理系統
2. 進入優惠券管理頁面
3. 新增優惠券（設定名稱、代碼、折扣類型、金額等）
4. 管理優惠券狀態（啟用/停用）
5. 查看優惠券使用統計
6. 匯出優惠券資料

### 用戶操作流程
1. 在會員中心或優惠券頁面查看可用優惠券
2. 領取想要的優惠券
3. 購物時在結帳頁面選擇優惠券
4. 系統自動驗證優惠券並計算折扣
5. 完成訂單後優惠券標記為已使用

## 功能特色

1. **完整的 CRUD 操作**: 支援優惠券的增刪改查
2. **多種折扣類型**: 支援百分比和固定金額折扣
3. **使用限制**: 可設定最低訂單金額、使用次數限制、有效期限
4. **用戶管理**: 記錄每個用戶的優惠券領取和使用情況
5. **狀態管理**: 優惠券可啟用/停用，自動檢查過期狀態
6. **統計功能**: 提供優惠券使用統計和匯出功能
7. **權限控制**: 後台功能僅限管理員使用

## 注意事項

1. 優惠券代碼必須唯一
2. 用戶不能重複領取同一張優惠券
3. 已使用的優惠券不能重複使用
4. 過期或停用的優惠券無法使用
5. 結帳時會驗證優惠券的有效性和使用條件
6. 所有管理員操作都會記錄在操作日誌中
