商品頁面與商品詳細頁彈窗圖片一致性測試

測試說明

此測試會檢查商品頁面和商品詳細頁的加入購物車彈窗是否顯示相同的圖片

實作確認清單

  • ✓ ProductsView.vue (商品頁面): openAddToCart 使用 ...product 保留完整商品物件
  • ✓ ProductDetailView.vue (商品詳細頁): addToCart 使用 ...productData 保留完整商品物件
  • ✓ ProductAddToCartModal.vue: 統一使用 product.primary_image?.image_path 顯示圖片
  • ✓ 圖片來源: 都使用商品管理頁面上傳的主圖 (primary_image)
  • ✓ 資料結構: 兩個頁面傳遞相同的 primary_image 結構
