🔗 推薦商品導航功能測試

測試目標

驗證在商品詳情頁面的「相關推薦」標籤中，點擊「查看詳情」按鈕是否能正確跳轉到對應的商品頁面。

功能說明

推薦功能整合位置：
- 原本的獨立 ProductRecommend 組件已移除
- 推薦功能已整合到 ProductTabs 組件的「相關推薦」標籤中
- 使用真實 API 數據替代模擬數據

路由配置

{ path: '/products/:id', name: 'product-detail', component: ProductDetailView }

跳轉函數

const viewProduct = (productId: number) => { router.push({ name: 'product-detail', params: { id: productId } }); };

測試步驟

步驟 1： 啟動開發服務器
cd frontend npm run dev
步驟 2： 訪問商品詳情頁面
例如：http://localhost:5173/products/1
步驟 3： 點擊「相關推薦」標籤
確認推薦商品列表正確顯示
步驟 4： 點擊任一推薦商品的「查看詳情」按鈕
驗證是否正確跳轉到對應商品頁面
步驟 5： 檢查 URL 變化
確認 URL 格式為 /products/{商品ID}

預期結果

✅ 推薦商品正確顯示（僅顯示已發布商品）
✅ 點擊「查看詳情」按鈕能成功跳轉
✅ URL 正確更新為目標商品頁面
✅ 新頁面正確載入目標商品資訊
✅ 新頁面的推薦列表重新載入相關商品

問題排查

如果跳轉不成功：
1. 檢查瀏覽器控制台是否有錯誤訊息
2. 確認 router 是否正確導入
3. 檢查路由名稱是否匹配
4. 驗證商品 ID 是否正確傳遞
如果推薦商品不顯示：
1. 檢查 API 端點是否運行
2. 確認資料庫中有已發布的商品
3. 查看網路請求是否成功
4. 檢查組件掛載時是否正確調用 API

技術實現細節

API 端點： GET /api/v1/products/{id}/recommendations
推薦策略： 同類別 → 價格相近 → 熱門商品
過濾條件： 僅顯示 published = 1 的商品
預設數量： 最多 6 個推薦商品

相關檔案

frontend/src/components/ProductTabs.vue (推薦功能整合) frontend/src/views/ProductDetailView.vue (已移除 ProductRecommend) backend/app/Http/Controllers/ProductController.php (API 實現) frontend/src/router/index.ts (路由配置)
