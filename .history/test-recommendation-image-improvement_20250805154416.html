🖼️ 推薦商品圖片處理改進報告

改進目標

統一推薦商品的圖片處理方式，使其與商品頁面的圖片呈現手法保持一致，提供更好的視覺體驗和載入性能。

主要改進內容

1. 圖片 URL 處理統一化

改進前：
// 簡單的路徑拼接 const getProductImage = (product) => { if (product.image) { return product.image.startsWith('/') ? product.image : `/${product.image}`; } return '/images/placeholder.jpg'; };
改進後：
// 使用統一的 getImageUrl 函數 import { getImageUrl } from '@/utils/imageUtils' const getProductImage = (product) => { if (product.primary_image?.image_path) { return getImageUrl(product.primary_image.image_path); } if (product.image) { return getImageUrl(product.image); } return getImageUrl('/images/placeholder.jpg'); };

2. 錯誤處理機制

改進前：
const handleImageError = (event) => { const img = event.target; img.src = '/images/placeholder.jpg'; };
改進後：
const handleImageError = (event) => { const img = event.target; img.src = getImageUrl('/images/placeholder.jpg'); }; const handleImageLoad = (event) => { const img = event.target; console.log('Image loaded successfully:', img.src); };

3. 圖片樣式改進

改進前：
<img :src="getProductImage(recommendation)" :alt="recommendation.name" class="w-full h-32 object-cover rounded-lg" @error="handleImageError" />
改進後：
<img :src="getProductImage(recommendation)" :alt="recommendation.name" class="w-full h-48 object-cover rounded-lg bg-[#f9f6f1] border" @error="handleImageError" @load="handleImageLoad" />

getImageUrl 函數功能

核心功能：
✅ 處理 Cloudinary CDN URL
✅ 處理本地存儲路徑 (/storage)
✅ 處理相對路徑
✅ 修正錯誤格式 (/https://...)
✅ 環境變數支援 (VITE_API_BASE_URL)
✅ 調試日誌輸出

測試步驟

步驟 1： 打開瀏覽器開發者工具
檢查 Console 和 Network 標籤
步驟 2： 訪問商品詳情頁面
例如：http://localhost:5174/products/1
步驟 3： 點擊「相關推薦」標籤
觀察推薦商品圖片的載入情況
步驟 4： 檢查圖片載入日誌
Console 中應該顯示 getImageUrl 的調試信息
步驟 5： 驗證圖片載入成功
Console 中應該顯示 "Image loaded successfully" 訊息
步驟 6： 測試錯誤處理
可以手動修改圖片 URL 測試錯誤回退機制

注意事項

性能考量：
- getImageUrl 函數會輸出調試日誌，正式環境可考慮移除
- 更大的圖片尺寸可能影響載入時間
- 建議配合圖片懶載入機制使用
