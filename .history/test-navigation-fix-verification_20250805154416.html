🔧 推薦商品導航問題修復報告

問題描述

現象： 點擊推薦商品的「查看詳情」按鈕後，頁面只會跳到最上面，並沒有跳轉到對應的商品頁面。

問題原因分析

根本原因：
ProductDetailView 組件在路由參數變化時沒有重新載入商品數據。當從商品1跳轉到商品2時，雖然 URL 改變了，但組件沒有重新載入新商品的資料，所以看起來像是沒有跳轉。

修復方案

解決方案 1： 在 ProductDetailView 中添加路由監聽
// 監聽路由變化，當商品 ID 改變時重新載入 watch(() => route.params.id, async (newId) => { if (newId) { await loadProduct() } })
解決方案 2： 重構商品載入邏輯
// 載入商品數據 const loadProduct = async () => { const id = route.params.id try { const res = await axios.get(`/api/v1/products/${id}`) product.value = res.data.product } catch (error) { console.error('Failed to load product:', error) } }
解決方案 3： 添加調試信息
// 查看商品詳情（增強版） const viewProduct = (productId: number) => { console.log('viewProduct called with ID:', productId); console.log('Current route:', router.currentRoute.value); const id = Number(productId); if (!id || isNaN(id)) { console.error('Invalid product ID:', productId); return; } try { router.push({ name: 'product-detail', params: { id: id.toString() } }); console.log('Navigation attempted to product-detail with id:', id); } catch (error) { console.error('Navigation error:', error); } }

修復後的測試步驟

步驟 1： 打開瀏覽器開發者工具的 Console 標籤
步驟 2： 訪問商品頁面
例如：http://localhost:5174/products/1
步驟 3： 點擊「相關推薦」標籤
觀察 Console 中的推薦商品數據載入日誌
步驟 4： 點擊任一推薦商品的「查看詳情」按鈕
觀察 Console 中的導航日誌
步驟 5： 確認頁面內容變化
檢查商品名稱、圖片、價格等是否更新為新商品的資訊

預期修復結果

✅ Console 顯示正確的商品 ID 和導航信息
✅ URL 正確更新為新商品路徑
✅ 頁面內容完全更新為新商品資訊
✅ 新頁面的推薦列表重新載入相關商品
✅ 頁面滾動位置正確（不會只是跳到頂部）

除錯提示

如果仍有問題：
1. 檢查瀏覽器 Console 是否有 JavaScript 錯誤
2. 確認 API 端點是否正常回應（http://localhost:8000）
3. 檢查前端服務器是否正常運行（http://localhost:5174）
4. 確認路由配置是否正確
5. 檢查組件是否正確掛載和更新

技術改進

核心改進：
- 添加了路由參數監聽功能
- 重構了商品載入邏輯
- 增強了錯誤處理和調試信息
- 確保 SPA 路由正確運作
- 提升了用戶體驗的流暢度
