📋 測試步驟

  1. 前端測試

    前往 http://localhost:5173/contact

    填寫表單並提交，檢查：

    • 表單驗證是否正常
    • 送出按鈕狀態變化
    • 成功/錯誤訊息顯示
    • 表單清空功能
  2. 後端測試

    檢查後端日誌:

    cd backend && php artisan log:tail
  3. 郵件測試

    由於目前 MAIL_MAILER=log，郵件會寫入 storage/logs/laravel.log

    查看郵件內容:

    cd backend && tail -f storage/logs/laravel.log

🔧 API 端點詳情

端點： POST /api/v1/contact

請求格式：

{
  "name": "客戶姓名",
  "email": "customer@example.com",
  "message": "客戶訊息內容",
  "to_email": "yijiaxiang88@gmail.com"
}

回應格式：

{
  "success": true,
  "message": "訊息已成功送出，我們會盡快回覆您！"
}

📧 郵件配置說明

目前郵件設定為開發模式（MAIL_MAILER=log），正式環境需要配置 SMTP：

MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=yijiaxiang88@gmail.com
MAIL_PASSWORD=your_app_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=yijiaxiang88@gmail.com
MAIL_FROM_NAME="一佳香肉脯行"
