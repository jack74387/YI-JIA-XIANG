資料庫結構

新增的欄位

欄位名稱 資料類型 說明 範例
nutrition_info JSON 營養資訊（熱量、蛋白質等） {"calories": "320大卡", "protein": "25公克"}
ingredients TEXT 主要成分 豬肉、糖、鹽、醬油、香料
allergens TEXT 過敏原資訊 本產品含有大豆製品
shelf_life VARCHAR(100) 保存期限 60天（未開封）
storage_instructions TEXT 保存方式 常溫保存，開封後請冷藏
origin VARCHAR(100) 產地 台灣
package_info JSON 包裝規格資訊 [{"name": "600g 大包裝", "description": "適合家庭分享"}]

營養資訊 JSON 格式

{ "calories": "320大卡", "protein": "25公克", "fat": "18公克", "carbohydrates": "12公克", "sodium": "850毫克", "sugar": "8公克", "fiber": "2公克", "calcium": "50毫克", "iron": "3毫克", "vitaminC": "5毫克" }

包裝規格 JSON 格式

[ { "name": "600g 大包裝", "description": "適合家庭分享" }, { "name": "300g 中包裝", "description": "適合小家庭" }, { "name": "150g 隨手包", "description": "適合個人享用" } ]

後端 API 更新

產品創建/更新 API

端點： POST /admin/products 或 PUT /admin/products/{id}
新增支援的欄位：
// 營養和成分資訊欄位 'nutrition_info' => 'nullable|array', 'ingredients' => 'nullable|string', 'allergens' => 'nullable|string', 'shelf_life' => 'nullable|string|max:100', 'storage_instructions' => 'nullable|string', 'origin' => 'nullable|string|max:100', 'package_info' => 'nullable|array'

請求範例

POST /admin/products Content-Type: application/json { "name": "黃金豬典豬肉鬆", "category_id": 1, "description": "經典風味豬肉鬆...", "nutrition_info": { "calories": "320大卡", "protein": "25公克", "fat": "18公克", "carbohydrates": "12公克", "sodium": "850毫克" }, "ingredients": "豬肉、糖、鹽、醬油、香料", "allergens": "本產品含有大豆製品", "shelf_life": "60天（未開封）", "storage_instructions": "常溫保存，開封後請冷藏", "origin": "台灣", "package_info": [ { "name": "600g 大包裝", "description": "適合家庭分享" } ] }

前端顯示

ProductTabs 組件更新

功能：
✅ 動態顯示營養資訊（如果資料庫有資料則顯示，否則顯示預設值）
✅ 動態顯示成分資訊和過敏原
✅ 動態顯示保存期限和保存方式
✅ 動態顯示包裝規格
✅ 支援多語言營養標籤轉換

後台管理界面建議

🎯 需要在後台添加的編輯區域：

1. 營養資訊編輯器

建議使用動態表單，支援添加/刪除營養項目：

  • 熱量（大卡）
  • 蛋白質（公克）
  • 脂肪（公克）
  • 碳水化合物（公克）
  • 鈉（毫克）
  • 其他營養素...

2. 成分資訊區域

  • 主要成分（文字輸入框）
  • 過敏原資訊（文字輸入框）
  • 產地（下拉選單或文字輸入）

3. 保存資訊區域

  • 保存期限（文字輸入框，如："60天（未開封）"）
  • 保存方式（文字區域，支援多行）

4. 包裝規格編輯器

動態列表，支援添加多個包裝選項：

  • 包裝名稱（如：600g 大包裝）
  • 包裝描述（如：適合家庭分享）

測試方法

1. 資料庫測試

php artisan tinker $product = App\Models\Product::find(1); $product->nutrition_info = ["calories" => "320大卡", "protein" => "25公克"]; $product->ingredients = "豬肉、糖、鹽、醬油、香料"; $product->shelf_life = "60天（未開封）"; $product->save();

2. API 測試

使用 Postman 或 curl 測試產品更新 API

3. 前端測試

訪問商品詳情頁面 → 點擊「商品規格」標籤 → 查看營養資訊顯示
